# 🎂 Interactive Birthday Website

An interactive birthday website built with **HTML, CSS, and JavaScript**.

## ✨ Features

- 🎥 Full-width landscape hero video
- 🎂 Interactive birthday cake
- 🕯 Click candles to blow them out
- 💨 Smoke animation
- 🎉 Confetti celebration
- ❤️ Floating hearts
- 🎈 Balloons animation
- 📷 Two-photo gallery
- 💌 Typewriter birthday message
- 🎁 Final surprise section
- 🎵 Background music
- 📱 Responsive design
- 🚀 Ready for GitHub Pages and Render

## 🎂 How It Works

1. Visitor opens website.
2. Hero video starts automatically.
3. Scroll down to the birthday cake.
4. Click every candle.
5. Each candle:
   - Flame disappears
   - Smoke appears
   - Blow sound plays
6. When all candles are out:
   - 🎉 Confetti
   - 🎈 Balloons
   - ❤️ Hearts
   - Birthday message appears
7. Scroll to view two photos.
8. Click **Open My Gift**.
9. Final surprise appears.

## 🚀 Deploy to Render

1. Create a new **Static Site**.
2. Connect your GitHub repository.
3. Leave **Build Command** empty.
4. Publish Directory:

```
.
```

5. Click **Deploy**.
